# Lulies Tavern — Member Badge Draw

Internal iPad-first web app for Lulies Tavern staff to manage members and run
the weekly badge draw.

## Structure

- `backend/` — Ruby on Rails API (SQLite, session-cookie auth)
- `frontend/` — Next.js (App Router, Tailwind, server-rendered)

## Development

```
# backend
cd backend && bin/rails server

# frontend
cd frontend && npm run dev
```
